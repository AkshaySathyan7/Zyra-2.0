
# Zyra 2.0 (Java)

Zyra 2.0 is a desktop voice assistant built with JavaFX. Features:
- Chat GUI with chat-bubble UI
- Text-to-speech (FreeTTS)
- Weather (OpenWeatherMap), News (NewsAPI), Wikipedia summary
- Jokes, facts, timers, simple math, YouTube opening, reminders
- Text and optional speech modes

## Run
1. Add your API keys in `ZyraApp.java`
2. Build & run:
   mvn clean javafx:run
